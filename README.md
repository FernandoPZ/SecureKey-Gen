# KeyForge 🛡️
Un generador de credenciales criptográficamente seguro desarrollado en Python.

## Características
- **Generación Segura:** Utiliza el módulo `secrets` de Python para entropía real.
- **Versatilidad:** Crea contraseñas alfanuméricas o llaves hexadecimales.
- **Medidor de Seguridad:** Evaluación en tiempo real de la fortaleza de la clave.
- **Interfaz Intuitiva:** Desarrollado con Tkinter para una experiencia ligera.

## Cómo ejecutar
1. Asegúrate de tener Python 3 instalado.
2. Clona este repositorio.
3. Ejecuta `python main.py`.
